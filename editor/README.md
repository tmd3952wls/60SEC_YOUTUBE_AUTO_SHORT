# 쇼츠 편집기

렌더링한 쇼츠의 편집본(EDL)을 화면에서 고치고 다시 렌더링하는 편집기입니다. 이 컴퓨터에서만 열립니다.

## 실행
- `run_editor.bat` 을 더블클릭하면 서버가 켜지고, 브라우저에 편집기가 자동으로 열립니다.
- 또는 터미널에서 `python editor/server.py`.
- 주소는 http://127.0.0.1:47615 입니다. 다른 프로그램이 이 포트를 쓰고 있으면 47616, 47617… 순서로 빈 번호를 찾습니다.
- 끌 때는 서버 창을 닫거나 Ctrl+C.

## 화면 구성
| 위치 | 하는 일 |
|---|---|
| 위 막대 | 작업, 편집본 버전(v1~), 미리 볼 영상 선택 · 이 박자 미리보기 · 새 버전 저장 · 전체 렌더링 · 설정 |
| 왼쪽 | 박자 목록(B1~), 영상 제목 2줄 · 효과음 목록(들어 보기, 넣기) · 실사용 영상 목록 |
| 가운데 | 9:16 미리보기 |
| 오른쪽 | 선택한 박자 편집: 내레이션 대본 · 원본 대사 · 자막 · 장면 · 효과음 · 메모 · JSON 직접 고치기 |
| 아래 | 타임라인: 영상(장면 썸네일) · 자막 · 목소리(내레이션/원본) · 효과음 |

## 작업 순서
1. 영상을 보며 고칠 박자를 고릅니다. 타임라인 블록을 누르거나, 박자 목록을 누르거나, ← → 키로 옮깁니다.
2. 오른쪽에서 고칩니다. 고친 박자에는 주황 점이 붙습니다.
   - 색 강조: 글자를 드래그하고 색 버튼을 누르면 `[yellow:글자]` 형태로 바뀝니다.
   - 자막 줄바꿈은 `|` 로 넣습니다.
   - 감탄사(와우! 등)는 "단독"을 켭니다.
3. **이 박자 미리보기**를 누르면 고친 박자만 몇 초~몇십 초 안에 렌더링됩니다. 저장하지 않은 내용도 미리 볼 수 있습니다.
4. **새 버전 저장**(Ctrl+S)을 누르면 항상 새 파일(v6, v7…)로 저장합니다. 기존 편집본은 그대로 남습니다.
5. **전체 렌더링**을 누르면 저장하지 않은 내용을 먼저 새 버전으로 저장한 뒤, `full_v6.mp4` 처럼 새 영상으로 만듭니다. 이미 있는 영상은 덮어쓰지 않습니다.

편집하다 창을 닫아도 저장하지 않은 내용은 브라우저에 보관됩니다. 다시 열면 "불러오기" 안내가 나옵니다.

## 검사 규칙 (스타일 프리셋)
`editor/presets/*.json` 의 `rules` 가 편집 중 경고로 나옵니다. 기본 프리셋 `해외쇼쇼`는 다음을 검사합니다.
- 쓰지 않는 표현("샤크" 등)
- 다른 말과 붙은 감탄사
- 1초보다 짧게 보이는 자막
- 대본과 자막 나누기가 서로 다른 경우

프리셋의 `config` 는 렌더링 설정을 덮어씁니다. 지금은 자막을 아래에 놓고, 최소 길이는 0.75초입니다.

## 설정
- **API 키:** Typecast(필수), Fish/Claude/OpenAI(선택). 프로젝트의 `.env` 파일에만 저장되고, 화면에 다시 보이지 않습니다.
- **목소리 ID:** Typecast 목소리 ID(`tc_…`).
- **효과음 폴더:** 폴더를 바꾸면 "효과음 목록 다시 만들기"를 눌러 주세요.
- **필요한 프로그램:** ffmpeg, ffprobe, WhisperX(.venv-whisperx)가 설치되어 있는지 보여 줍니다.

## 파일
- `server.py`: 파이썬 기본 라이브러리만 쓰는 서버(127.0.0.1 전용)
- `render_worker.py`: 렌더 작업. 결과 옆에 `<영상>_log.txt` 와 `<영상>_meta.json` 을 만듭니다.
- `static/`: 화면(HTML/CSS/JS, 빌드 없음)
- `presets/`: 스타일 프리셋

## 다른 사람에게 줄 때 (나중에)
- `.env`(내 API 키)와 효과음 폴더는 포함하지 않습니다. 받는 사람은 설정 화면에서 자기 키와 폴더를 넣습니다.
- 설치 파일로 묶는 일은 아직 하지 않았습니다(3차 단계).
