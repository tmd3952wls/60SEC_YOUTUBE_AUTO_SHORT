# EDL → CapCut 프로젝트

편집본(`vN_edl.json`)을 CapCut 프로젝트로 만듭니다. CapCut에서 바로 고칠 수 있도록 재료가 트랙별로 나뉘어 들어갑니다.

## 실행
1. `make_capcut.bat` 을 더블클릭합니다.
2. 작업 이름(예: `vulcan_rattrap`)과 편집본(예: `v5_edl.json`)을 입력합니다.

터미널에서는 이렇게 실행합니다.
```
python -m shorts.capcut --job vulcan_rattrap --edl v5_edl.json
```

- 한 번 렌더링한 뒤 재료를 나눠 담으므로, 렌더링과 같은 시간이 걸립니다.
- 같은 이름의 프로젝트가 이미 있으면 `_2`, `_3` 처럼 새 이름으로 만듭니다. 기존 CapCut 프로젝트는 건드리지 않습니다.
- **CapCut이 켜져 있을 때**는 프로젝트 폴더만 만들고 목록 등록은 미룹니다. CapCut을 완전히 끈 뒤 `register_capcut.bat` 을 실행하세요.
  - 목록 파일은 등록 전에 `root_meta_info.json.bak-shorts-…` 로 백업합니다.

## CapCut 안의 트랙
| 트랙 | 내용 |
|---|---|
| 영상 | 장면(샷)마다 자른 클립 1080×1050. 크롭·확대·색 번쩍임·빨간 원은 클립 안에 이미 들어 있습니다. |
| 내레이션 / 원본 대사 | 박자별 목소리. 렌더러와 같은 크기로 맞춰져 있습니다. |
| 효과음 1, 2… | 렌더러가 고른 효과음(기본: opus-sound-layer 실제 녹음). 같은 위치·같은 크기이며, 겹치는 소리는 다른 트랙에 들어갑니다. |
| 자막 | CapCut 텍스트(Cafe24 Ohsquare). 강조 색과 원화 줄(작은 초록 글씨)이 들어 있습니다. |
| 제목 1, 2 | 위쪽 제목 두 줄 |

## 렌더 영상과 다른 점
- **자막 효과:** 네온 빛과 1프레임 번짐은 옮겨지지 않습니다. 대신 검은 외곽선과 흐림을 낮춘 그림자를 넣었습니다(사용자가 CapCut에서 직접 맞춘 값, `shorts/capcut.py` 의 `SUB_STROKE`, `SUB_SHADOW_DIFFUSE`).
- **CapCut에서 자막 스타일을 "모든 자막에 적용"하면** 자막 위치가 화면 가운데로 초기화될 수 있습니다. 스타일을 바꾼 뒤에는 위치를 다시 확인하세요.
- **소리 끝 처리:** 렌더 영상의 리미터, 효과음 공간 울림(room), ±2% 음높이 변화는 CapCut에 없습니다. 음량은 같게 맞췄습니다.
- **글자 크기·위치:** 기존 CapCut 표지 이미지로 맞춘 근사값입니다(`shorts/capcut.py` 의 `PX_PER_SIZE`, `LINE_H`).
- **클립 여유분:** 샷 클립에는 앞뒤 여유분이 없어서, 컷을 늘리려면 원본에서 다시 가져와야 합니다.

## 파일
- `shorts/capcut.py`: 변환기
- `shorts/capcut_template.json`: CapCut이 직접 만든 파일에서 뽑은 틀(개인 경로·기기 ID는 지움)
- `jobs/<작업>/capcut/<프로젝트>/`: CapCut이 쓰는 샷·목소리·효과음 파일. 이 폴더를 지우면 CapCut 프로젝트가 깨집니다.
- 재료는 그대로 두고 프로젝트만 다시 쓰려면:
  ```
  python -m shorts.capcut --job 작업 --reuse 프로젝트이름
  ```

## 주의
CapCut이 업데이트로 프로젝트 파일을 암호화하면 이 방법은 더는 쓸 수 없습니다. 9.7.1에서는 동작을 확인했습니다.
